# Vulnerability Map

> **Intentional coursework vulnerabilities.** This application is a
> deliberately vulnerable security lab (see `SECURITY-LAB-NOTICE.md`).
> Every registered vulnerability is required by the assignment and must
> not be "fixed". All data is synthetic; do not deploy.

The authoritative registry of intentional vulnerabilities now lives at
the repository root: **[`VULNERABILITIES.md`](../VULNERABILITIES.md)**
— per-vulnerability summaries (affected feature, required role,
prerequisites, reproduction, expected proof, reset procedure) with
links to the full writeups in [`vulnerabilities/`](vulnerabilities/).

Exactly four vulnerabilities exist. Nothing else in the codebase is
intentionally vulnerable — accidental bugs are treated as defects, not
features.
